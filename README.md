# Linux System Monitoring Dashboard

A Bash-based Linux system monitoring dashboard built on Ubuntu Desktop.

## Project Overview

This project monitors important Linux system resources using Bash scripting and standard Linux commands.

## Planned Features

- CPU monitoring
- Memory monitoring
- Disk monitoring
- Process monitoring
- Network monitoring
- System information
- Logged-in users
- Automatic dashboard refresh
- System alerts

## Technologies

- Ubuntu Linux
- Bash Shell
- Git
- GitHub
